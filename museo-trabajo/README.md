# Museo Horizonte — práctica de HTML

## Archivos incluidos
- `index.html`: página principal y sección de contacto.
- `galeria-exposiciones.html`: galería con las dos imágenes facilitadas.
- `precios.html`: tabla de tarifas.
- `fotos/`: imágenes usadas en la galería.

## Cómo verlo
Abre `index.html` en un navegador. Los tres archivos HTML y la carpeta `fotos` deben permanecer juntos para que los enlaces y las imágenes funcionen.

## Entrega en GitHub
La práctica pide subir estos archivos a un repositorio llamado `museo-<tu-nombre>`. Crea un repositorio con ese nombre en tu cuenta de GitHub y sube todo el contenido de esta carpeta. El repositorio no se ha creado automáticamente.
